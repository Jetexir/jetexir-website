  - Create unlimited custom order statuses

  - Set the default status for the "Check payments" method
  - Color-code statuses with a custom admin background color
  - Rename statuses to match your workflow
---

WooCommerce's built-in statuses don't fit every workflow. Custom Order Statuses lets you define exactly the steps your
orders go through, from "Pending Review" to "Shipped via Courier", and rename existing statuses so they match how you
actually work.

Control the behavior of your workflow too: choose the default order status, the fallback status used when an order is
deleted, and the default status for orders paid via the "Check payments" method. Color-code each status with a custom
admin background so your team can read the order queue at a glance.
